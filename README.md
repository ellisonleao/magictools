### Submission Rules

To get your pull request accepted, your link must follow these rules:

- **Game dev only**: must be explicitly about game development, not a general tool.
- **HTTPS only**: only secure (`https://`) links are accepted.
- **100+ GitHub stars**: repo links need at least 100 stars.
- **Alphabetical order**: place it in the correct position within its section.
- **License tag required**: start with `:free:`, `:tada:`, `:moneybag:`, or `:money_with_wings:` (not required for Blogs and Portals, Videos/Podcasts, Game Jams, and Communities).

### License Legends

- :free: - Free
- :tada: - Open Source
- :moneybag: - Paid
- :money_with_wings: - Partially Free
